# AI Interview Preparation Platform

An AI-powered MERN stack application that helps users prepare for technical interviews by analyzing resumes, generating interview questions, identifying skill gaps, and creating personalized preparation roadmaps.

---

## Features

- User Authentication (JWT + Cookies)
- Resume Upload (PDF)
- AI Generated Interview Questions
- Technical + Behavioral Questions
- Skill Gap Analysis
- Personalized Preparation Plan
- Resume PDF Generator
- Protected Routes
- MERN Stack Architecture
- Modern Responsive UI

---
